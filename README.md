# ☀️ Personal Daily Briefing App

A lightweight, beginner-friendly Python script that aggregates real-time weather and daily inspiration into a clean terminal dashboard. Built as a quick weekend hackathon project!

## 🚀 Features

* **Real-Time Weather:** Fetches current weather and temperature for your desired city instantly.
* **Daily Motivation:** Pulls a random inspirational quote from a public API to kickstart your day.
* **Zero Complex Setup:** Uses free public APIs that do not require complicated API keys to get started.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Library:** `requests` (for HTTP API calls)

---

## 📦 Installation & Setup

Follow these steps to get the project running locally on your machine:

### 1. Clone or Download the Project
Navigate to your project directory in your terminal:
```bash
cd daily_briefing
```

### 2. Install Dependencies
Install the required `requests` library using pip:
```bash
pip install requests
```

### 3. Run the Application
Execute the Python script:
```bash
python app.py
```
